DIR / 01

Design Direction

A visual language drawn directly from Tony Stark's HUD in Iron Man (2008): a black void, pale bright-cyan wireframe, and radial diagnostics that rotate while the system thinks. One token system drives both the desktop web console and the iOS app, so they read as the same machine.

Ground

Near-black, blue-biased void. Everything glows against darkness — the interface never sits on white.

Cyan wireframe

Pale arc-reactor blue for structure, strokes and live text. Thin lines, generous glow.

Radial motion

Concentric rings that spin and pulse while Jarvis is calculating — the signature "thinking" gesture.

Stark gold

The Mark III callback. A single warm accent for your own voice and alerts — used sparingly.

SYS / 03

Typography

The films used Arame Mono — a technical, monospaced display face. The system leans monospace for all HUD chrome (labels, readouts, the wordmark), with a clean geometric sans for anything you actually read at length.
